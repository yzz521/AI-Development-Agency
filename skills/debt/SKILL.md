# Skill: debt — 收割债务台账

## 触发

- "记一下债务 / 这个简化先欠着"
- "收割 agency: 注释"
- "看看我们有多少债务"

## 过程

1. 运行 `agency debt [dir]`（默认规范库根，可传项目目录）。
2. 解读输出：每行 = `文件:行号 | 上限 | 升级路径 | 状态`。
3. 向用户汇报：债务总数、含升级路径的条数、`no-trigger`（无升级路径）清单及风险。

## 边界

- 只读不改：不修改代码、不补注释、不替用户决定是否消除债务。
- 不把 Markdown 正文里的 `agency:` 引用当债务（只认代码注释）。
- 不评价债务是否值得现在消除——只展示台账。

## 退出

输出台账 + no-trigger 提醒后即结束；用户要求消除债务时另开任务。
