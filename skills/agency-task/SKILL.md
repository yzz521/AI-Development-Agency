# Skill: agency-task — 生成任务单留证据

## 触发

- "留个证据 / 按规范留痕"
- "生成任务单"
- "把这次改动记录一下"
- 任何 L2 及以上任务收尾时（主动提示用户）

## 过程

1. 运行 `agency task --title "<任务标题>" [项目目录]`。
2. 按模板如实填写，四类内容必须来自本次会话的真实记录：
   - **读取的文件**：本次实际读过的路径（不是"应该读"的）
   - **修改的文件**：本次实际改过的路径
   - **验证命令与结果**：真实执行过的命令与其真实输出结论
   - **规则反馈**：本次哪条规则生效 / 被违反 / 缺失
   - **规范路由回执**：会话第一行的 `agency-route:` 原文；没有就写「无」，禁止补编
3. 告知用户任务单路径，并提示可用 `agency audit` 交叉核对。

## 边界

- **只记录已发生的事实**：没读过的文件不写、没跑过的命令不写、没看到的结果不编。
- 不为了让任务单好看而补跑验证——要补跑就先跑完再写。
- 不修改代码、不修改既有任务单。
- 不代替 `agency feedback`：规则反馈在任务单里是一个字段，独立反馈仍走 feedback。

## 退出

输出任务单路径 + 核对方式后即结束。
