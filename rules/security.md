# Security Rules

## 摘要（注入用）

- 默认最小权限；密钥不进源码、不进日志。
- 所有外部输入视为不可信；SQL 必须参数化。
- API 必须认证、授权和输入校验；医疗数据访问必须可审计。
- 安全问题按 Blocker / High / Medium / Low 分级并给出修复建议。

## 全文

1. 默认最小权限。
2. 秘钥不进源码、不进日志。
3. 所有外部输入都视为不可信。
4. SQL 必须参数化。
5. API 必须进行认证、授权和输入校验。
6. 医疗数据访问必须可审计。
7. 安全问题按 Blocker / High / Medium / Low 分级并明确修复建议。
