# Security Rules

## 摘要（注入用）

- 默认最小权限；密钥不进日志（不进源码见 `rules/global.md`）。
- 所有外部输入视为不可信；SQL 必须参数化。
- API 必须认证、授权和输入校验。

## 全文

1. 默认最小权限。
2. 秘钥不进日志；不进源码见全局规则。
3. 所有外部输入都视为不可信。
4. SQL 必须参数化。
5. API 必须进行认证、授权和输入校验。
6. 安全问题按 Blocker / High / Medium / Low 分级并明确修复建议（安全审查任务必做，写代码任务不默认展开）。

医疗数据访问审计、敏感日志字段见 `rules/healthcare.md`，仅医疗项目加载。
