# Feature Development Workflow

## 适用
新增业务功能、页面、接口、规则配置等。

## 流程
1. `product-manager`：问题、目标、验收标准。
2. `requirements-analyst`：字段、流程、边界。
3. `software-architect`：影响范围和技术方案（需要时）。
4. `ui-designer`：页面与交互（涉及 UI 时）。
5. `sqlserver-dba`：DDL、索引、迁移（涉及数据时）。
6. `java-developer` / `python-developer`：后端实现。
7. `vue-developer` / `react-developer`：前端实现。
8. `qa-engineer` / `api-tester`：验证。
9. `security-reviewer`：高风险或敏感数据场景。
10. `code-reviewer`：最终代码检查。
11. `ai-tech-lead`：汇总。

## 完成定义
需求可验收、代码已验证、数据库变更可回滚、关键风险已记录。
