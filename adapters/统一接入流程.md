# AI Development Agency 统一接入流程

## 目标

让不同 Coding Agent 使用同一套研发规范，而不用为每个工具维护一套 Agent 内容。

## 第一层：中央 Agency

建议放：

```text
~/ai/AI-Development-Agency/
```

它是“AI 研发团队知识库”。

包含：

```text
agents/
rules/
workflows/
context/
contracts/
artifacts/
validation/
```

## 第二层：项目

每一个具体业务项目：

```text
your-project/
└── AGENTS.md
```

项目 `AGENTS.md` 负责：

- 项目简介
- 技术栈
- 项目命令
- Agency 路径
- 项目特殊规则
- 默认使用的 Agent
- 验证方式

## 第三层：工具

```text
Codex
Reasonix
DeepSeek Harness
```

工具只负责运行。

---

# 推荐信息流

```text
用户任务（直接说，不必先跑命令）
   ↓
项目 AGENTS.md 规范路由段
（Cursor 另有 .cursor/rules/agency-router.mdc）
   ↓
命中规则的「摘要（注入用）」
   ↓
读取真实代码
   ↓
执行
   ↓
测试 / Review
   ↓
最终结果
```

---

# 不推荐

不要：

```text
每个项目复制一整份 Agency
```

不要：

```text
每个工具维护一套独立 Agent Prompt
```

不要：

```text
一次性加载全部 Agent
```

不要：

```text
为了“多 Agent”而拆成大量子 Agent
```

推荐：

```text
中央 Agency
+
项目 AGENTS.md
+
工具适配
```
