# Project Context

## 项目定位

这是一个以企业软件研发、医疗 AI 应用、医保审核和数据处理为主要场景的 AI 辅助研发体系。

## 典型系统组成

```text
Web UI
  ↓
Vue / React
  ↓
Java / Python API
  ↓
SQL Server / AI Services
  ↓
医疗业务数据 / OCR / RAG / 审核规则
```

## 研发目标

1. 提高需求到代码的交付速度。
2. 降低 AI 生成代码的返工率。
3. 统一 Java / Vue / Python / SQL Server 工程规范。
4. 让医疗领域规则在 AI 工作流中得到明确约束。
5. 形成可复用的项目级 AI 开发模板。
