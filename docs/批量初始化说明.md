# 批量初始化说明

## 第一次使用

假设：

```text
~/workspace/
├── AI-Development-Agency/
├── project-a/
├── project-b/
└── project-c/
```

执行：

```bash
cd ~/workspace/AI-Development-Agency
./scripts/init-all.sh ~/workspace
```

自动创建：

```text
项目/
├── AGENTS.md
└── .ai/
    └── agency -> ../../AI-Development-Agency
```

已有 `AGENTS.md` 不覆盖。

## 单项目

```bash
./scripts/init-project.sh ../project-a
```

## 检查

```bash
./scripts/doctor.sh ../project-a
```

## 递归

```bash
RECURSIVE=1 ./scripts/init-all.sh ~/workspace
```

## 新项目

```bash
./scripts/init-project.sh ../new-project
```

## 删除软链接

```bash
./scripts/remove-link.sh ../project-a
```

## 路径原则

脚本只创建相对软链接。软链接位于项目的 `.ai/` 目录内，相对路径从 `.ai/` 起算，因此同级项目为：

```text
.ai/agency -> ../../AI-Development-Agency
```

路径由脚本按项目实际深度自动计算，`RECURSIVE=1` 下嵌套更深的项目会得到相应层数的 `../`。

不会把机器绝对路径写进项目，因此整个 workspace 移动后，只要相对目录关系不变，无需修改项目 AGENTS.md。
