# 工具接入说明

## 推荐分工

| 工具 | 推荐定位 |
|---|---|
| Codex | 主力 Coding Agent |
| Reasonix | Planner / Research / Subagent / Review |
| DeepSeek Harness | 模型、Tool、MCP、运行能力层 |
| AI Development Agency | Agent / Rule / Workflow / Context |

## 推荐架构

```text
                 AI Development Agency
                         │
             ┌───────────┼───────────┐
             ↓           ↓           ↓
           Codex      Reasonix   DeepSeek Harness
             │           │           │
             └───────────┼───────────┘
                         ↓
                    实际项目
                         ↓
                      代码
```

## 第一阶段建议

先不要做真正的 Multi-Agent Runtime。

先跑通：

```text
项目 AGENTS.md
      ↓
Agency Agent
      ↓
Rule
      ↓
真实代码
      ↓
测试
```

确认 Agent 真正能稳定完成任务后，再使用 Reasonix Subagent 或其他 Runtime 做自动编排。

## 第二阶段

选择复杂任务：

```text
医保审核规则配置
```

跑完整 Workflow：

```text
Product
→ Requirements
→ Architecture
→ DB
→ Java
→ Vue
→ QA
→ Security
→ Review
```

再观察哪些环节需要独立 Subagent。

## 第三阶段

再考虑：

```text
Task Router
Agent Scheduler
Context Manager
Artifact Manager
Review Loop
Evaluation
```

形成真正的 AI Software Factory。
