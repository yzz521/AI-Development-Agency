# 规则清单（待圈选）

> 用途：把中央库**现在实际在约束写代码的条文**摊开，供你标「留红线 / 留条件加载 / 下沉到项目 / 删除」。
> 本文件不改变生效规则。你回复编号即可，例如：`A3 删除`、`B1 留红线`。

建议口径：

| 标记 | 含义 |
| --- | --- |
| 留红线 | 写入常驻摘要（每次写代码都注入）+ 适合以后做 CI |
| 留条件加载 | 只在命中该语言/领域时注入摘要 |
| 下沉项目 | 中央库删掉或改成「以项目 AGENTS.md 为准」 |
| 删除 | 不再约束 AI |
