# 示例：医保审核规则配置功能

这是用于验证 AI Development Agency 的第一个推荐测试场景。

## 用户需求

新增医保审核规则配置功能，支持：

- 规则新增
- 规则修改
- 启用 / 禁用
- 规则版本
- 规则查询
- 操作审计

## 推荐风险

L3。

原因：

- 医保业务
- 数据库
- 权限
- 规则版本
- 审计
- 后端 + 前端

## 推荐 Workflow

```text
feature-development
```
